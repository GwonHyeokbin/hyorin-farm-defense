# 효린이의 농장 지키기

**Hyorin's Farm Defense**는 설치나 계정 없이 브라우저에서 즐기는 한국어 2D 웨이브 생존 게임입니다. 효린이를 직접 움직여 농장과 작물을 지키고, 방어 보상으로 장비를 강화하세요.

게임 자산은 프로젝트에 포함되어 있습니다. 페이지가 열린 뒤에는 외부 이미지, 음원, API를 불러오지 않습니다. 브라우저 저장 공간과 이어하기 코드는 사용자의 기기에만 저장됩니다.

## 로컬에서 실행하기

Node.js 20 이상이 필요합니다. Windows PowerShell에서는 `npm.cmd`를 사용하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 여세요. 모바일에서는 게임 화면을 누른 채 손가락을 움직여 플레이합니다.

## 빌드와 테스트

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npm.cmd run preview
```

빌드 결과는 `dist/`에 만들어집니다. 빌드 명령은 TypeScript 검사를 수행한 뒤 Vite로 정적 파일을 만듭니다. 저장 코드, 웨이브 시작, 점수, 농장 피해, 전투 상태 복원을 확인하는 단위 테스트는 실제 브라우저나 네트워크 API에 의존하지 않습니다.

## 조작법

- 이동·공격: PC에서는 마우스 왼쪽 버튼을 누른 채 움직이면 효린이가 포인터를 따라가며 가장 가까운 적을 자동 조준해 새총을 쏩니다. 모바일 세로 화면에서는 방향 패드와 공격 버튼을 사용하고, 가로 화면에서는 키패드 없이 게임 화면을 누른 채 끌어 이동·자동 공격합니다.
- 모바일 화면: 화면의 회전 버튼은 브라우저가 허용할 때 가로 잠금을 요청하고, 전체 화면 버튼은 별도로 동작합니다. YouTube 앱 등 일부 앱 내부 브라우저는 회전이나 전체 화면을 제한할 수 있으므로 버튼 안내가 나오면 기기를 직접 회전해 주세요.
- 탄환 선택: 게임 화면 위에서 BB탄, 강철 BB탄, 돌맹이 중 선택합니다. 돌맹이는 적을 넉백시킵니다.
- 추가 공격: 가까운 적은 큰 돌에 맞아 그로기 상태가 됩니다. 정비 시간에 포인트 35개로 바위 강타를 구매하면 주변 적을 자동으로 기절시킵니다.
- 농장 수호 펫: 정비 시간에 누니(40), 양이(60), 마루(75)를 각각 포인트로 한 번씩 구매할 수 있습니다. 구매한 고양이는 농장을 순찰하고 가까운 침입자를 자동 공격합니다.
- 일시정지: `Esc` 또는 화면의 일시정지 버튼

적을 처치해 경험치를 모으면 레벨이 오르고, 레벨마다 공격 속도가 1% 빨라집니다. 효린이는 가까운 침입자를 자동으로 조준하고 탄환도 적을 따라갑니다. 두더지는 땅속에서 밭 가까이 나타나고, 토끼는 작물을 향해 달려듭니다. 까마귀는 밭으로 급강하하며, 멧돼지는 농장 시설로 돌진합니다. 다섯 번째 웨이브마다 왕멧돼지가 나타납니다.

웨이브를 막으면 효린이의 체력과 전투 상태가 완전히 회복되고, 열매 포인트를 얻습니다. 정비 시간에 포인트를 써 공격력, 연사, 이동, 방어, 체력을 강화하거나 바위 강타를 구매하고 농장을 수리할 수 있습니다. 침입자 수·체력·공격력을 더 낮추고 효린이의 연사와 탄환 피해를 높여 편하게 플레이할 수 있도록 조정했습니다.

## 이어하기 코드와 자동 저장

일시정지 메뉴에서 두 종류의 코드를 만들 수 있습니다.

- **간편 이어하기 코드**: 점수, 웨이브, 체력, 작물·시설, 업그레이드와 구매한 펫을 보관하는 안전 시점 저장입니다. 진행 중이던 적과 투사체는 포함하지 않고 정비 단계에서 시작합니다.
- **전체 상태 백업 코드**: 전투 중 적, 투사체, 진행 중인 웨이브, 난수 상태까지 보관합니다. 길이가 긴 코드는 화면의 구간을 순서대로 이어서 복사할 수 있습니다.

메인 메뉴의 **코드로 이어하기**에서 코드를 붙여 넣으세요. 입력과 복원은 브라우저 안에서 이루어지며 서버나 계정이 필요하지 않습니다. 코드를 가진 사람은 그 코드에 담긴 저장 상태를 복원할 수 있으니 안전하게 보관하세요. 체크섬은 손상 탐지용이며 암호화나 부정행위 방지 기능은 아닙니다.

게임은 12초 간격, 일시정지, 웨이브 완료 시 브라우저 자동 저장을 갱신합니다. 브라우저 데이터나 사이트 저장 공간을 지우면 자동 저장과 개인 최고 점수가 사라질 수 있으므로, 보관할 진행은 이어하기 코드를 따로 저장하세요.

## 개인 기록

최고 점수, 최근 플레이, 도달 웨이브는 현재 브라우저의 LocalStorage에 저장합니다. 별도 서버나 온라인 랭킹은 제공하지 않습니다. 브라우저 저장 기능이 비활성화되어도 게임 플레이 자체는 계속할 수 있습니다.

## GitHub 저장소에 올리기

1. GitHub에서 빈 저장소를 만듭니다. 공개 웹 게임으로 배포하려면 저장소 공개 설정을 확인하세요.
2. 이 `hyorin-farm-defense` 폴더의 파일을 저장소 루트에 업로드합니다. `node_modules/`와 `dist/`는 올리지 않습니다.
3. `main` 브랜치에 push하면 GitHub Actions가 의존성을 설치하고 테스트, 빌드, Pages 배포를 차례로 실행합니다.
4. 저장소의 **Settings → Pages → Build and deployment**에서 **GitHub Actions**를 선택합니다.
5. Actions의 배포 작업이 성공하면 같은 Pages 설정 화면에 공개 주소가 표시됩니다. 저장소 하위 경로를 포함한 주소로 빌드되므로 사용자 정의 도메인이나 루트 경로를 가정하지 않습니다.

게임을 업데이트하려면 소스를 수정해 `main`에 push하세요. 테스트 또는 프로덕션 빌드가 실패하면 해당 실행에서 Pages 배포 단계가 실행되지 않습니다.

## 알려진 범위

- 지원 코드 형식은 `HFD1`입니다. 이후 다른 형식 버전으로 업데이트되면 지원하지 않는 버전을 한국어로 안내합니다.
- 개인 랭킹만 지원하며 모든 이용자가 공유하는 온라인 랭킹은 없습니다.
- 터치 조작과 반응형 레이아웃을 제공하지만 실제 브라우저의 다양한 기기별 체감은 기기에서 직접 확인하는 것이 좋습니다.
